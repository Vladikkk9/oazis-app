# OAZIS ESTATE — Telegram Mini App

Готовое к публикации мини-приложение: главная, 5 каталогов со встроенной читалкой, 6 рекомендованных публикаций, страница агентства, квиз из 5 вопросов, подборка объектов с открытыми и скрытыми предложениями, форма заявки (демо).

Сборка не нужна: обычные HTML/CSS/JS-модули. Достаточно загрузить папку на любой HTTPS-хостинг.

## Структура

```
index.html
assets/
  css/app.css             — дизайн-система Liquid Glass (цвета, стекло, светлая/тёмная тема).
                            Шрифт системный: SF Pro на iPhone, Roboto на Android — грузить ничего не нужно
  img/objects/            — фото объектов (оригиналы, извлечённые из PDF-каталогов)
  img/covers/             — обложки каталогов
  js/config/              — ВСЁ РЕДАКТИРУЕМОЕ СОДЕРЖИМОЕ
    app.js                — режим заявок (демо/боевой), аналитика
    agency.js             — тексты об агентстве, цифры, контакты
    catalogs.js           — список каталогов
    posts.js              — 6 публикаций канала
    objects.js            — база объектов для квиза
    quiz.js               — вопросы и варианты ответов
  js/core/                — Telegram API, роутер, подбор, заявки, аналитика
  js/views/               — экраны
catalogs/<id>/            — PDF + страницы каталога для читалки (p01.jpg…)
server/bitrix-proxy.worker.js — пример серверной интеграции с Битрикс24
```

## Как редактировать

- **Публикации** — `assets/js/config/posts.js`. У четырёх постов стоят временные заголовки (`placeholder: true`): Telegram не показывает их содержимое вне приложения. Впишите `title`, `summary`, `topic` и удалите `placeholder`.
- **Объекты** — `assets/js/config/objects.js`. Цены хранятся по каждому каталогу отдельно (`prices`), т. к. в PDF они различаются. Расхождения по срокам и характеристикам — в `conflicts`, приложение показывает их пользователю.
- **Каталог** — положите PDF в `catalogs/<id>/`, нарезанные страницы `p01.jpg…` рядом, обложку в `assets/img/covers/<id>.jpg`, добавьте запись в `catalogs.js`.
- **Вопрос квиза сделать условным** — добавьте в `quiz.js` поле `showIf: (answers) => answers.type !== 'commercial'`.

## Публикация на GitHub Pages

1. Создайте репозиторий на github.com (например, `oazis-miniapp`), сделайте его Public.
2. Загрузите **содержимое** папки `oazis-miniapp` в корень репозитория (Add file → Upload files, или через git).
3. Settings → Pages → Source: *Deploy from a branch*, Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты приложение будет доступно по адресу `https://<логин>.github.io/oazis-miniapp/`.

## Подключение к Telegram

1. В [@BotFather](https://t.me/BotFather): `/newbot` → имя и username бота → сохраните токен (никому не передавайте).
2. `/newapp` → выберите бота → название, описание, картинка 640×360 → **Web App URL** = адрес с GitHub Pages → короткое имя, например `app`. Получите ссылку вида `https://t.me/<бот>/app`.
3. Кнопка меню бота: `/mybots` → бот → Bot Settings → Menu Button → URL приложения.
4. В канале опубликуйте пост со ссылкой `https://t.me/<бот>/app` (или кнопкой через бот-постер, например @ControllerBot). Ссылка открывает Mini App прямо в Telegram.

Глубокие ссылки: `https://t.me/<бот>/app?startapp=quiz`, `…?startapp=catalog_altai`, `…?startapp=object_rizalta`, `…?startapp=read`.

## Заявки → Битрикс24

Сейчас `lead.endpoint = null` → демо-режим: форма валидируется, данные собираются в формат `crm.lead.add`, но не отправляются. Пользователь видит честное сообщение «Демо-режим».

Чтобы включить:
1. В Битрикс24: Приложения → Разработчикам → Входящий вебхук с правом `crm`. Создайте источник лида `UC_TG_MINIAPP`.
2. Разверните `server/bitrix-proxy.worker.js` (Cloudflare Workers, Яндекс Cloud Functions или свой сервер). Задайте секреты `BOT_TOKEN`, `BITRIX_WEBHOOK`, `ALLOWED_ORIGIN`.
3. Впишите URL прокси в `assets/js/config/app.js` → `lead.endpoint`.

Прокси проверяет подпись Telegram (`initData`), поэтому подделать заявку из браузера нельзя. Вебхук Битрикс24 никогда не попадает в клиентский код. Перед запуском приведите в соответствие с 152-ФЗ политику обработки персональных данных.

## Аналитика

`assets/js/core/analytics.js` — события: открытие приложения, разделы, каталоги, скачивание PDF, переходы к постам, старт/шаги/завершение квиза, просмотр объектов, клики по скрытым предложениям, открытие формы, отправка заявки. Сейчас они пишутся в консоль и `window.dataLayer`. Для Яндекс Метрики подключите счётчик в `index.html` и укажите `yandexMetrikaId` в `config/app.js`. Имя, телефон и данные Telegram в события не попадают.
